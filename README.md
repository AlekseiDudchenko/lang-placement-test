# Deutsch-Test — адаптивный тест уровня немецкого языка

Одностраничное приложение, которое определяет уровень немецкого по шкале
CEFR (A1–C2). Работает **полностью в браузере**: без сервера, без сборки,
без внешних зависимостей — данные никуда не отправляются.

## Запуск

Просто откройте `index.html` в браузере. Также проект можно опубликовать
на любом статическом хостинге (GitHub Pages, Netlify и т.п.).

## Как работает адаптивный алгоритм

Тест построен на IRT (Item Response Theory): 2PL-модель, в которой
дискриминация `a` едина для всех заданий (что эквивалентно модели Раша
в перемасштабированных логитах):

1. **Оценка способности.** Уровень испытуемого θ оценивается байесовски
   (EAP): после каждого ответа апостериорное распределение θ уточняется
   по вероятностной модели `P(верно) = 1 / (1 + e^(−a(θ−b)))`, где `b` —
   сложность задания, `a` — дискриминация.
2. **Подбор вопросов.** Следующим выбирается задание с максимальной
   информацией Фишера вблизи текущей оценки θ — то есть сложность вопроса
   всё время держится «на грани возможностей» испытуемого. Дополнительно
   балансируются навыки (грамматика / лексика / чтение) и добавляется
   небольшая случайность, чтобы тест не повторялся.
3. **Критерий остановки.** Тест завершается, когда стандартная ошибка
   оценки θ падает ниже порога (уровень определён надёжно), но не раньше
   12 и не позже 20 вопросов.
4. **Результат.** Итоговая θ отображается на шкалу CEFR; «уверенность» —
   это доля апостериорной вероятности, попавшая в полосу выбранного уровня.

По симуляциям (300 виртуальных испытуемых на уровень) тест угадывает
точный уровень в 75–91 % случаев, а ошибается максимум на один соседний
уровень — при средней длине теста 12–14 вопросов.

Симуляцию и санити-чек банка заданий можно запустить локально
(нужен только Node.js): `node tests/simulate.js`.

> **Примечание.** После каждого ответа подсвечивается правильный вариант —
> это удобно для самопроверки, но при повторных прохождениях результат
> будет завышен, так как банк заданий конечен (72 вопроса).

## Структура

```
index.html        — разметка (три экрана: старт, тест, результат)
css/styles.css    — стили
js/questions.js   — банк из 72 заданий A1–C2 (грамматика, лексика, чтение)
js/engine.js      — адаптивный движок (IRT: EAP-оценка, подбор по информативности)
js/app.js         — логика интерфейса
tests/simulate.js — санити-чек банка + симуляция точности (node tests/simulate.js)
```

## Как расширять банк заданий

Добавьте объект в `js/questions.js`:

```js
{ id: "b1-13", level: "B1", b: -0.5, skill: "gram",
  q: "Формулировка с пропуском ___.",
  opts: ["правильный ответ", "дистрактор 1", "дистрактор 2", "дистрактор 3"] }
```

Правильный вариант всегда первый — при показе варианты перемешиваются.
Параметр `b` — сложность в логитах (ориентиры: A1 ≈ −2.6, A2 ≈ −1.6,
B1 ≈ −0.6, B2 ≈ 0.4, C1 ≈ 1.4, C2 ≈ 2.4).
